# SwiftDrop development diary — October 2026

## 2026-10-12 — Integrated media gallery and players

Added paged MediaStore browsing for photos, videos and music, section-specific runtime permissions (including Android 14 partial visual grants), search, selection and local previews. Media3 handles audio/video and the photo viewer supports pinch zoom. Installed apps retain their APK export path and now display package icons. Selection feeds the unchanged Nearby manager. Added permission and Compose UI tests; CI builds a signed development APK and runs the UI suite on an emulator. Physical transfer, decoder and permission behavior remain for device QA.

## 2026-10-12 — Explicit CI development signing

The reference UI workflow passed and uploaded its APK, but the default signing-cache path did not exist on the runner. Configured an explicit development-only keystore in runner temporary storage, generation when absent, an optional Gradle environment override, and caching of that exact file. Local tests/lint/assembly passed and the APK certificate matches the supplied key. Cache retention is temporary; durable release signing remains separate.

## 2026-10-12 — Reference-inspired native sharing UI

Implemented the selected blue/cyan visual direction in the existing Compose screens. Added original plane vectors, a persisted skippable welcome, responsive category cards, real app/history search and direction filters, smaller expandable settings, clearer startup failure states and completion actions. Large fonts get stacked actions; security text can scroll. Preserved Nearby and SAF/app export wiring, session history, verification and saving. Final local checks passed 25 tests, lint (0 errors / 11 warnings), debug assembly and signature verification. Android 15 ATD confirmed normal Wi-Fi grants. Physical transfer testing remains required.

## 2026-10-12 — Correct normal Wi-Fi permissions

The device screenshot reported Nearby status 8032 / MISSING_PERMISSION_ACCESS_WIFI_STATE. Both normal Wi-Fi permissions were removed by maxSdkVersion=31 on newer Android versions. Removed that cap, keeping runtime prompts limited to the existing SDK-specific nearby/file requirements. Added four tests that inspect the actual merged manifest, including its permission caps, package identity and broad-access exclusions. Local unit tests (25), lint and debug compilation passed before committing. Physical radio transfer still requires two-device verification.

## 2026-10-11 — Premium Android UI v0.2.0-alpha

Fetched the existing alpha branch before editing. Delivered five staged changes: centralized theme/icons, home/navigation, secure discovery and callback-backed progress, persisted appearance/localization, and category/app sharing with accessibility/permission regression checks.
